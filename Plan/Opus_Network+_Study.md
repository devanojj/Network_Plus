### 🔴 RED FLAG #1 — Subnetting: Last Host calculation is WRONG

**File:** [Subnetting with Subnet Mask.md](file:///Users/devano/Documents/Obsidian/Network+/Concepts/S/Subnetting/Subnetting%20with%20Subnet%20Mask.md) — Line 43

```
***Last Host***
Broadcast Address - 1 : ==165.245.79.255==
```

**Problem:** The last usable host for subnet 165.245.64.0/20 should be **165.245.79.254**, not 165.245.79.255. The value 165.245.79.255 IS the broadcast address. You correctly calculated it above as the broadcast, then wrote the same value for last host. It should be:
- Broadcast: 165.245.79.255 ✅
- Last Host: 165.245.79.**254** ❌ (you wrote .255)
