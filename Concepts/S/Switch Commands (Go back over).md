#domain/1-0-Networking-Concepts

**show mac-address-table**
- **Platform**: Switches (mostly Layer 2)
- **Purpose**: Displays the MAC address table of the device.

**ip link show**
- **Platform**: Linux 
- **Purpose**: Shows network interfaces and link status.

**getmac**
- **Platform**: Windows
- **Purpose**: Displays MAC addresses for local network adapters.

**show route**
- **Platform**: Router / Layer 3 Switch
- **Purpose**: Displays the routing table.

**show interface**
- **Platform**: Router / Switch
- **Purpose**: Displays interface status, not just configuration.

**show config**
- **Platform**: Router / Switch
- **Purpose**: Displays interface **performance stats** and some configuration.

**show arp**
- **Platform**: Router / Switch
- **Purpose**: Displays **IP-to-MAC mappings** learned by the device.

**show vlan**
- **Platform**: Switch
- **Purpose**: Displays VLAN configuration.

**show power**
- Displays PoE status per port.
- Shows allocated power, available power, and PoE usage.
- Use for diagnosing issues with IP phones, APs, cameras.
