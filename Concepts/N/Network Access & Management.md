#domain/1-0-Networking-Concepts


### In-Band Management
- Management traffic uses the same network as production data
- If the network is down, management access is lost
Examples: SSH, SNMP & Telnet



### Out-of-Band Management

- Uses a separate management path
- Works even if the primary network is down
- Used for troubleshooting and initial configuration
Examples:
- Console port (serial connection)
- Dedicated management interface
- Cellular modem
