### Network Operations
Warm site $\rightarrow$ when primary fails, data will be restored and secondary site will be activated 

Backup Incremental $\rightarrow$ least amount of time and lowest disk space, this only backups those files which were changed

Backup Differential $\rightarrow$ backs up all the data changed since the last full backup
